# SSL Code feedback: practice repo

A copy of [`code-feedback`](https://github.com/swisssoftwarelaboratory/code-feedback) with the same issue form and labels, for testing **Report a problem** while it's being built. SSL Code files here when its server runs with `SSLCODE_REPORT_REPO=swisssoftwarelaboratory/code-feedback-sandbox`.

**Everything here is public**, like in `code-feedback`: the issues, and the `report/...` branches in each tester's fork. Report only throwaway test threads.
